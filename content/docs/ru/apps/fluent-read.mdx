  В консоли New API, в разделе «Системные настройки» -> «Настройки чата», можно добавить следующие быстрые параметры для удобного заполнения в FluentRead на странице управления токенами:

<Callout type="info">
  🌊
  FluentRead — это плагин для перевода в браузере с открытым исходным кодом, предназначенный для обеспечения чтения, близкого к родному языку.
</Callout>

- Адрес проекта: [https://github.com/Bistutu/FluentRead](https://github.com/Bistutu/FluentRead)

## 🌟 Основные возможности

### Интеллектуальный движок перевода

- **Поддержка множества движков**: Поддерживается 20+ движков перевода.
- **Традиционные переводы**: Microsoft Translator, Google Translate, DeepL и др.
- **Большие ИИ-модели**: OpenAI, DeepSeek, Kimi, Ollama и др.
- **Пользовательские движки**: Возможность настройки собственного сервиса перевода.

### Иммерсивное чтение

- **Двуязычный параллельный просмотр**: Оригинал и перевод отображаются параллельно для облегчения чтения.
- **Перевод по выделению**: Выделите любой текст для мгновенного получения перевода.
- **Одно копирование**: Быстрое копирование перевода для повышения эффективности.
- **Перевод всей страницы**: Одним нажатием плавающей кнопки переводите всю веб-страницу без обновления.

### Конфиденциальность и настройка

- **Защита конфиденциальности**: Все данные хранятся локально, код открыт и прозрачен.
- **Высокая настраиваемость**: Богатые возможности настройки для различных сценариев.
- **Полностью бесплатно**: Открытый исходный код, некоммерческий проект.

## 🚀 Настройка

### Импорт конфигурации из консоли New API (рекомендуется)

После установки плагина FluentRead откройте консоль New API -> страницу управления токенами — появится подсказка о добавлении FluentRead.

![Подсказка](/assets/fluentread/hint.png)

Выберите модель и нажмите «Заполнить в FluentRead одним нажатием». Появится окно подтверждения для проверки корректности данных.

![Подтверждение](/assets/fluentread/confirm.png)

После подтверждения импорта конфигурация New API в FluentRead будет активирована.

![Результат настройки](/assets/fluentread/fluentread.png)

### Ручная настройка в FluentRead

![Ручная настройка](/assets/fluentread/configuration.png)

| Параметр            | Значение                              |
| ------------------- | ------------------------------------- |
| Сервис перевода     | NewAPI                                |
| Токен доступа       | Ключ NewAPI                           |
| API NewAPI          | Адрес развертывания NewAPI (без /v1)  |
| Модель              | Выберите из списка или укажите свою   |
| Пользовательская модель | Название модели                    |
