## Способы подключения к New API

### Способ 1: импорт одним щелчком

1. В боковом меню консоли New API выберите «Управление токенами» и найдите нужный токен.
   <img src="/assets/deepchat/1-Enter-API-key.png" alt="Переход в управление токенами" width="240" />

2. В действиях с токеном выберите **DeepChat**
   <img src="/assets/deepchat/2-API-key-deepchat.png" alt="Выберите DeepChat" width="360" />

3. Браузер запустит DeepChat, подтвердите открытие приложения
   ![Открыть DeepChat](/assets/deepchat/3-open-deepchat.png)

4. В окне предварительного просмотра импорта провайдера DeepChat проверьте конфигурацию
   ![Подтверждение конфигурации DeepChat](/assets/deepchat/4-deepchat-ok.png)

5. Откройте список моделей и выберите модель New API для начала работы
   ![Открыть список моделей](/assets/deepchat/5-open-models.png)

### Способ 2: ручной импорт

1. В консоли New API скопируйте API‑ключ и адрес сайта
   ![Руководство по ручной настройке New API](/assets/deepchat/7-new-api-manual-guidance.png)

2. В настройках DeepChat добавьте или отредактируйте провайдер New API, укажите адрес API и API‑ключ
   ![Руководство по ручной настройке DeepChat](/assets/deepchat/6-deepchat-manual-guidance.png)

3. Откройте список моделей и выберите модель New API для начала работы
   ![Открыть список моделей](/assets/deepchat/5-open-models.png)
