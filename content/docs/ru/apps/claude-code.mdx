## Настройка AI-модели

### Инструкция для Windows

#### 1. Установка Node.js

Для работы Claude Code требуется среда Node.js.

<Callout type="info" title="Шаги по установке Node.js">
  - Откройте браузер и перейдите на https://nodejs.org/
  - Нажмите «LTS» для загрузки (рекомендуется долгосрочная поддерживаемая версия)
  - После загрузки дважды щелкните файл .msi
  - Следуйте инструкциям мастера установки, оставляя настройки по умолчанию
</Callout>

<Callout type="warn" title="Примечания для Windows">
  - Рекомендуется использовать PowerShell вместо CMD
  - При возникновении проблем с правами доступа попробуйте запустить от имени администратора
  - Некоторые антивирусы могут ложно срабатывать, добавьте в белый список
</Callout>

#### 2. Установка Git Bash

<Callout type="warn" title="Примечания для Windows">
  В среде Windows для установки Claude Code необходимо использовать Git Bash. После установки переменные среды и использование Claude Code выполняются в обычном PowerShell или CMD.
</Callout>

<Callout type="info" title="Загрузка и установка Git для Windows">
  - Перейдите на https://git-scm.com/downloads/win
  - Нажмите «Download for Windows», чтобы загрузить установочный пакет
  - Запустите загруженный .exe файл
  - В процессе установки оставьте настройки по умолчанию, нажимайте «Next» до завершения
</Callout>

  ```bash
  git --version
  ```

  Если отображается номер версии, установка прошла успешно.
</Callout>

#### 3. Установка Claude Code

<Callout type="info" title="Установка Claude Code">
  Откройте PowerShell и выполните следующую команду:

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```

  Эта команда загрузит и установит последнюю версию Claude Code из официального репозитория npm.
</Callout>

![windows-img-09.webp](/assets/claude_code/windows-img-09.webp)

<Callout type="info" title="Добавьте ~/.local/bin в PATH (только если требуется)">
  ```powershell
  [Environment]::SetEnvironmentVariable('Path', ([Environment]::GetEnvironmentVariable('Path','User') + ";$HOME\.local\bin"), 'User')
  ```
</Callout>

<Callout type="info" title="Проверка установки Claude Code">
  После установки введите команду:

  ```bash
  claude --version
  ```

  Если отображается номер версии, поздравляем! Claude Code успешно установлен.
</Callout>

#### 4. Настройка переменных среды

<Callout type="info" title="Команда для быстрой настройки (Windows)">
  Для подключения Claude Code к вашему прокси-сервису необходимо установить несколько переменных среды:
</Callout>

```powershell
iex (irm 'https://raw.githubusercontent.com/QuantumNous/new-api-docs/refs/heads/main/helper/claude-cli-setup.ps1')
```

#### 5. Начало работы с Claude Code

Теперь вы можете начать использовать Claude Code!

<Callout type="info" title="Запуск Claude Code">
  Откройте PowerShell и запустите Claude Code:

  ```bash
  claude
  ```

  Для использования в конкретном проекте:

  ```bash
  # Перейдите в каталог вашего проекта
  cd C:\путь\к\вашему\проекту

  # Запустите Claude Code
  claude
  ```
</Callout>

#### 4. Решение распространенных проблем на macOS

<Callout type="info" title="Блокировка macOS из-за настроек безопасности">
  Если система блокирует запуск Claude Code:

  - Откройте «Системные настройки» → «Безопасность и конфиденциальность»
  - Нажмите «Всё равно открыть» или «Разрешить»
  - Или в терминале выполните: `sudo spctl --master-disable`
</Callout>
