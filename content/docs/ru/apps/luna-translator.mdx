## Функциональная поддержка

- **HOOK** В основном использует HOOK для извлечения текста из игр, подходит для всех распространённых и редких визуальных новелл.

- **Встроенный перевод** Некоторые игры позволяют встраивать перевод непосредственно в игру для полного погружения.

- **Эмулятор HOOK** Для большинства игр на NS/PSP/PSV/PS2 поддерживается считывание текста через эмулятор HOOK.

- **OCR** Встроенная модель OCR с высокой точностью, а также поддержка множества онлайн и офлайн OCR-движков для гибкого считывания любого текста.

- **Богатый выбор интерфейсов перевода** Поддерживаются практически все движки перевода, включая перевод большими языковыми моделями, офлайн-перевод и т.д.

- **Изучение языка** Поддержка сегментации японского текста и чтения фуригана, поддержка AnkiConnect и плагина Yomitan.

- **Синтез речи** Поддержка большого количества онлайн и офлайн движков синтеза речи.

- **Распознавание речи** На Windows 10 и Windows 11 можно использовать встроенное распознавание речи.

## Установка

Скачайте и установите в [документации LunaTranslator — Загрузка, запуск и обновление](https://docs.lunatranslator.org/ru/README.html)

## Подключение <WebsiteName /> в LunaTranslator

LunaTranslator поддерживает подключение к локально развёрнутому <WebsiteName />. Используйте только собственный развёрнутый <WebsiteName /> или убедитесь, что поставщик услуг имеет законное разрешение вышестоящего уровня и соблюдает требования. Не подключайте к производственной среде API-адреса или ключи из неизвестных источников.

### Быстрая настройка

1. В консоли <WebsiteName /> в разделе `Системные настройки` -> `Настройки чата` добавьте следующий быстрый параметр:

   ```json
   { "LunaTranslator": "lunatranslator://llmapi/base64?data={cheryConfig}" }
   ```

   ![add_config](/assets/luna_translator/add_config.png)

2. На вкладке **<WebsiteName />** -> `Консоль` -> `Управление токенами` выберите токен для использования в LunaTranslator, нажмите на стрелку рядом с кнопкой чата, выберите `LunaTranslator` — произойдёт переход в LunaTranslator с автоматической настройкой API-адреса и API-ключа.

   ![Переход в LunaTranslator](/assets/luna_translator/jump_to_app.png)

3. В **`LunaTranslator`** -> `Настройки` -> `Настройки перевода` -> `Большие модели` появится новая конфигурация интерфейса большой модели. Нажмите «Редактировать».

   ![Настройка API](/assets/luna_translator/api_setting.png)

4. Нажмите кнопку обновления рядом с выпадающим списком **model**, чтобы получить список моделей платформы <WebsiteName />, выберите или введите название модели, затем нажмите «ОК» для сохранения.

   ![Настройка модели](/assets/luna_translator/setting_model.png)

5. Убедитесь, что переключатель рядом с конфигурацией интерфейса **new_api** включён. Если он выключен, включите интерфейс для начала использования.

   ![Включение конфигурации](/assets/luna_translator/open_config.png)

### Ручная настройка

1. На вкладке **<WebsiteName />** -> `Консоль` -> `Управление токенами` получите API-ключ.

   ![Получение API-ключа](/assets/luna_translator/copy_api_key.png)

2. В **`LunaTranslator`** -> `Настройки` -> `Настройки перевода` -> `Большие модели` выберите «Добавить».

   ![Добавление API](/assets/luna_translator/add_api.png)

3. Скопируйте шаблон **Универсальный интерфейс большой модели** и добавьте новый интерфейс.

   ![Добавление API 2](/assets/luna_translator/add_api_2.png)

4. В **новом интерфейсе** укажите соответствующий API-адрес и API-ключ.

   ![Настройка API 1](/assets/luna_translator/setting_api.png)

   ![Настройка API 2](/assets/luna_translator/setting_api2.png)

5. Нажмите кнопку обновления рядом с выпадающим списком **model**, чтобы получить список моделей платформы <WebsiteName />, выберите или введите название модели, затем нажмите «ОК» для сохранения.

   ![Настройка API 3](/assets/luna_translator/setting_api3.png)

6. Нажмите переключатель рядом с **<WebsiteName />**, чтобы включить интерфейс и начать использование.

   ![Включение API](/assets/luna_translator/open_api.png)

Дополнительные способы использования см. в официальной документации LunaTranslator: [Документация LunaTranslator — Интерфейс перевода большой модели](https://docs.lunatranslator.org/ru/guochandamoxing.html)
