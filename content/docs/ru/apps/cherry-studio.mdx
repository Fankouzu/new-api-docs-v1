## Подключение к New API

### Заполнение параметров

Тип провайдера: тип, поддерживаемый New API  
API-ключ: получить в New API  
Адрес API: адрес сайта New API

Пожалуйста, используйте собственный развернутый New API или убедитесь, что сервис имеет легитимное вышестоящее разрешение и соблюдение требований. Не подключайте в рабочую среду API-адреса или ключи из непроверенных источников.
