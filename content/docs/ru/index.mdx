## Обзор

New API предоставляет полный набор RESTful API-интерфейсов, разделённых на две категории: **Интерфейсы моделей AI** и **Интерфейсы управления**. С помощью этих интерфейсов вы можете выполнять вызовы AI-функций и управлять системой.

<Callout title="Online-отладка">
  Вы можете посетить <a href="https://apifox.newapi.ai/">тренировочную площадку Apifox</a> для онлайн-тестирования и отладки API-интерфейсов, или просмотреть документацию ниже.
</Callout>
