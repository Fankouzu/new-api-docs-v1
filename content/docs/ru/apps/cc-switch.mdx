## Основные возможности

### 🔌 Управление Provider
- **Переключение в один клик** — переключение между конфигурациями API Claude Code, Codex и Gemini без необходимости вручную изменять переменные окружения или файлы конфигурации.
- **Поддержка нескольких эндпоинтов** — каждый Provider может иметь несколько эндпоинтов, с управлением API ключами и измерением задержки.
- **4 уровня конфигурации моделей** — поддержка детальной конфигурации моделей на четырех уровнях: Haiku / Sonnet / Opus / Custom.

### 🛠️ Управление MCP-серверами
- **Единое управление между приложениями** — управление MCP-серверами для Claude, Codex и Gemini с единой панели.
- **Три типа передачи** — поддержка stdio, HTTP, SSE (Server-Sent Events).
- **Автоматическая синхронизация** — унифицированный импорт/экспорт + двусторонняя синхронизация.

### 💬 Управление Prompts
- **Несколько предустановленных системных подсказок** — неограниченные пресеты, быстрое переключение.
- **Поддержка между приложениями** — Claude (`CLAUDE.md`), Codex (`AGENTS.md`), Gemini (`GEMINI.md`).
- **Markdown редактор** — CodeMirror 6 + предпросмотр в реальном времени.

### 🌐 Поддержка нескольких платформ
- **Настольное приложение** — нативные установочные пакеты для Windows, macOS, Linux.
- **Веб-версия** — решение для доступа через браузер на безголовых серверах / SSH-удаленных средах.
- **CLI-версия** — поддержка интерактивного режима командной строки и командного режима.

## Интеграция с Lychee AI

CC Switch поддерживает протокол Deep Link `ccswitch://`, позволяющий импортировать конфигурации Provider в один клик со страницы управления токенами Lychee AI.

### Шаги настройки

1. **На странице управления токенами Lychee AI нажмите на выпадающее меню соответствующего токена**
   В меню выберите опцию **CC Switch**, система автоматически запустит приложение CC Switch и отобразит окно конфигурации.

2. **Заполните конфигурацию в окне**
   ![Заполнение окна CC Switch](/assets/cc_switch/fill_dialog.png)

   Описание полей окна:
   - **Приложение**: переключение типа приложения вверху — **Claude** / **Codex** / **Gemini**, выберите целевое приложение по мере необходимости.
   - **Имя**: укажите имя для этой конфигурации (например, `My Claude`), чтобы в дальнейшем легко идентифицировать и переключать в CC Switch.
   - **Основная модель** (обязательно) — основная модель, используемая по умолчанию.
   - **Модель Haiku** — легкая и быстрая модель.
   - **Модель Sonnet** — сбалансированная модель.
   - **Модель Opus** — самая мощная модель.

   Все модели выбираются из выпадающего списка; если не выбраны, отображается «Выберите модель».

3. **Завершение настройки**
   Нажмите **«Открыть CC Switch»**, чтобы импортировать конфигурацию в CC Switch и начать использование; нажмите **«Отмена»**, чтобы отменить операцию.

## Способы установки

### macOS (рекомендуется Homebrew)

```shell
brew tap farion1231/ccswitch
brew install --cask cc-switch
```

### Windows

Скачайте `.msi` установщик или портативную версию `.zip` из [Releases](https://github.com/farion1231/cc-switch/releases).

### Linux

Скачайте `.deb` пакет или `.AppImage` из [Releases](https://github.com/farion1231/cc-switch/releases).

Пользователи ArchLinux:

```shell
paru -S cc-switch-bin
```

### Веб-версия (безголовый / SSH сервер)

```shell
wget https://github.com/farion1231/cc-switch/releases/latest/download/cc-switch-web-linux-x64.tar.gz
tar -xzf cc-switch-web-linux-x64.tar.gz
cd cc-switch-web/
./cc-switch-web
```

Порт по умолчанию `17666`, доступ через браузер по адресу `http://localhost:17666`.
