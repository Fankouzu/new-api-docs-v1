## Руководство по интеграции

Большинству приложений для подключения к <WebsiteName /> требуется только настроить следующую информацию:

1. **Адрес API**: адрес вашего сервиса <WebsiteName />
2. **Ключ API**: токен, сгенерированный в консоли <WebsiteName />
3. **Название модели**: выберите нужную модель

Подробные шаги настройки смотрите в документации каждого приложения.
