## Описание

Интерфейсы управления используют многоуровневую систему аутентификации. Общие уровни: **Открытый**, **Пользователь**, **Администратор**, **Root**.

## Метод аутентификации (выберите один из двух)

### Session

Получение сессии через интерфейс входа:

- `POST /api/user/login`

### Access Token (рекомендуется)

Передавайте в заголовке запроса:

```text
Authorization: Bearer {token}
```

Токен можно сгенерировать в разделе «Настройки профиля → Настройки безопасности → Токен доступа к системе».

## Обязательные заголовки запроса

Некоторые интерфейсы требуют указания заголовка с идентификатором пользователя:

```text
New-Api-User: {user_id}
```

Где `{user_id}` должен соответствовать текущему авторизованному пользователю.

## Уровни разрешений

- **Открытый (Public)**: аутентификация не требуется
- **Пользователь (User)**: требуется вход или Access Token
- **Администратор (Admin)**: требуются права администратора
- **Root**: максимальный уровень прав
